# @eduquiz/mobile

Application mobile d'EduQuiz basée sur Expo SDK 50+ avec Expo Router.
Cible iOS et Android, parcours apprenant et parent. Partage un maximum de
code avec `@eduquiz/web` via les paquets partagés (`@eduquiz/ui`,
`@eduquiz/types`, `@eduquiz/utils`, `@eduquiz/i18n`).

## Stack

- Expo SDK 50+ (Bare workflow géré).
- Expo Router (file-based routing).
- NativeWind pour styles Tailwind partagés web/mobile.
- TanStack Query et Zustand (identiques au web).
- i18next + react-i18next (FR par défaut, EN secondaire).
- Build et distribution via EAS Build (plan gratuit).
