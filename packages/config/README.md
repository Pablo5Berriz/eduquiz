# @eduquiz/config

Configurations partagées utilisées par tous les paquets du monorepo.

## Fichiers exposés (à compléter)

- `tsconfig-base.json` — configuration TypeScript stricte de référence (héritée
  via `extends` dans chaque paquet).
- `eslint.config.js` — flat config ESLint v9 (règles TypeScript, React, import,
  accessibility).
- `prettier.config.js` — format Prettier partagé.
- `tailwind.config.js` — tokens de design partagés web/mobile (couleurs,
  typographie, espacements).

## État actuel

Paquet scaffoldé (étape 0.1). Les fichiers de config concrets seront ajoutés à
l'étape 0.2 de la Phase 0.
